# wmiles81's Claude Code plugins

A plugin marketplace for Claude Code.

```
/plugin marketplace add wmiles81/claude-plugins
```

## Plugins

| Plugin | What it does |
|---|---|
| [helpwright](https://github.com/wmiles81/helpwright) | Adds a browsable, zero-dependency help/docs system to any project — 7 framework targets, generated infographics, a maintainer agent. `/plugin install helpwright` |
